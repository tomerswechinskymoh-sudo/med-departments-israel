# תור תגובות רציף — 12.11.2026

השינוי מפשט את העבודה עם אלפי תגובות: הטקסט, המחלקה המוצעת וציון ההמלצה מופיעים בכל כרטיס ברשימה. המחלקה המוצעת כבר נבחרת, אפשר להחליף אותה, ויש שני כפתורים עצמאיים: **פרסום תגובה** ו־**פרסום ציון המלצה**. אין צורך לפתוח חלונית, לסמן תיבות או לאשר שוב בחלון קופץ. הלחיצה עצמה היא החלטת האדמין על השיוך, הפרטיות והרכיב הנבחר.

הכרטיס נשאר במקום גם אחרי אישור כדי לאפשר לחיצה על הכפתור השני. הרשימה נטענת בהדרגה בגלילה עם סמן יציב, כך ששינוי סטטוס אינו מדלג על תגובות בהמשך. מסננים וכלי ייבוא וזכויות נמצאים באזורים מתקפלים. כפתור הכניסה בדשבורד הוא קישור דמוי כפתור בגודל תקין ובשורה מסודרת.

השרת מקבל פעולה נקודתית ובונה את ההחלטה מהנתונים הקיימים. אישור של רכיב אחד אינו מאשר בחירות שמורות בהמתנה או פריט שנדחה, ואינו מחליף תוכן של הרכיב השני. אישור נוסף באותו שיוך שומר על הרכיב שכבר אושר. החלפת המחלקה מבטלת את אישור הרכיב האחר ומחייבת לחיצה ידנית נוספת עליו. אפשר לבטל אישור טקסט או ציון בנפרד. בקרת גרסה מונעת דריסת החלטה מחלון אחר.

כל הגנות המקור, זכויות השימוש, הרשאות האדמין, CSRF, התאמת שורת הדירוג, מקור מאומת ומחלקה פעילה נשמרו. אין שינוי סכימה או ייבוא חוזר, ואין אישור או פרסום של נתוני ייצור כחלק מהפריסה. המקור נשאר כבוי. מקרים שאין להם התאמה בטוחה עדיין דורשים בחירת מחלקה; מוסד שונה או הקשר כלל בית החולים דורשים נימוק.
