# ספירת חוויות וכוכבים לפני התחברות

כרטיסי המחלקות מציגים כעת את ספירת החוויות המאושרות ואת ממוצע ההמלצה המאוחד גם לאורחים ולחשבונות שטרם אומתו. הסיכומים זהים למשתמש מחובר, כולל חיפוש בתוך מערכים, סינון למחלקות עם חוויות ומיון לפי כמות או דירוג.

שאילתת הסיכום קוראת רק מזהי שיוך, סימון פרסום ומספרי דירוג מאושרים. היא אינה קוראת טקסטים או פרטי משיבים. קריאת התגובות עצמן ממשיכה להשתמש בבדיקת ההרשאות הקיימת.

תנאי אישור החוויה, פרטיות, אימות מקור, אישור שימוש וכפתור הסתרת המקור נשמרים. הסיכום אינו נשמר במטמון המחלקות, כדי שהסתרה והחזרה יחולו גם על אורחים בקריאה הבאה.

אין מיגרציה או שינוי ברשומות הייצור. בדיקות ההסתרה וההחזרה רצות בענף מסד הנתונים המבודד, ושומרות את החלטות האישור והדירוגים המקוריים.
