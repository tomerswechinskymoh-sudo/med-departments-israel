# ניווט ואזור אישי לאחר התחברות

התפריט הראשי נשאר זמין לכל תפקידי המשתמשים, כולל אדמין. במקום התפריט המצומצם שכלל רק ניהול האתר, מוצגים חיפוש המחלקות, בחירת התמחות, אודות, שאלות נפוצות, הרשימה שלי ואזור אישי. הקישור לנציגים נשמר למשתמשים בעלי תפקיד נציג.

האזור האישי זמין לכל משתמש מחובר. כפתור ניהול האתר מופיע בתוך האזור האישי רק לאדמין; בדיקות ההרשאות בשרת ובנתיבי הניהול לא משתנות.

בהתאם לבקשת המשתמש, התחברות מוצלחת בטופס הראשי מפנה תמיד לחיפוש המחלקות באמצעות replace, גם אם קישור ההתחברות מכיל פרמטר next ישן. הודעות אימות המייל ואיפוס הסיסמה נשמרות.

בדיקות דפדפן מבצעות התחברות אמיתית עם חשבונות סטודנט ואדמין סינתטיים במסד הבדיקות המבודד בלבד. הסיסמאות הזמניות משוחזרות בסיום. נבדקים גם תפריט נייד, קישור מפת האתר, הרשאות ניהול וניתוב לאחר התחברות. אין שינוי בחשבונות הייצור או בנתוני הסקר.
